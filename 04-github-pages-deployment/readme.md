# GitHub Pages Deployment Workflow

This project is part of my [DevOps Projects](../README.md) repository.  
The goal of this project is to practice **Continuous Integration and Continuous Deployment (CI/CD)** using **GitHub Actions** and **GitHub Pages**.

📌 Project URL: [https://roadmap.sh/projects/github-actions-deployment-workflow](https://roadmap.sh/projects/github-actions-deployment-workflow)

---

## Project Description

A simple GitHub Actions workflow that automatically deploys a static website to **GitHub Pages** whenever the `index.html` file is changed.

---

## Features

- Deploys website automatically on every push to the `main` branch.  
- Workflow is triggered **only if files in `04-github-pages-deployment/` change**.  
- Uses **GitHub Actions** and publishes the website to **GitHub Pages**.
